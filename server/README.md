# 자연스러운 남성·여성 음성 연결하기

서버 없이 음성 설정 화면을 보는 것은 가능합니다. 실제 Nova·Onyx 재생에는 OpenAI API 계정과 아래 서버가 필요합니다. OpenAI API 사용료는 ChatGPT 구독과 별도입니다.

## 1. OpenAI API 준비

1. https://platform.openai.com 에서 프로젝트와 API 키를 만듭니다.
2. API 결제/크레딧을 설정하고 프로젝트 사용량 알림을 설정합니다.
3. 키는 Render의 비밀 환경 변수에만 넣습니다. GitHub·앱 설정·채팅에 넣지 않습니다.

## 2. Render 서버 만들기

1. https://render.com 에 로그인하고 GitHub 계정을 연결합니다.
2. **New → Blueprint**에서 `Min8309/mornig_block` 저장소와 `main` 브랜치를 선택합니다. 저장소 루트의 `render.yaml`이 서버 실행 방법을 제공합니다.
3. `OPENAI_API_KEY` 입력란에 발급한 API 키를 넣고 Blueprint를 생성합니다.
4. 서버 배포가 성공하면 `https://morningblock-voice-....onrender.com` 형태의 서비스 주소를 복사합니다. 정확한 주소는 Render가 생성한 값을 사용합니다.
5. 서비스 **Environment**에서 자동 생성된 `TTS_ACCESS_TOKEN` 값을 확인합니다. 이는 개인 서버 접속 토큰이며 OpenAI API 키와 다른 값입니다. 타인에게 공유하지 않습니다.

웹 미리보기 주소는 `TTS_ALLOWED_ORIGINS`에 이미 등록되어 있습니다. 다른 웹 주소를 사용한다면 정확한 origin을 쉼표로 구분해서 추가합니다. Render가 제공하는 `RENDER_EXTERNAL_URL`을 음성 URL로 자동 사용합니다. 다른 호스팅에서는 `PUBLIC_BASE_URL`을 설정합니다.

무료 Render 인스턴스는 유휴 상태에서 정지하거나 첫 요청이 늦어질 수 있습니다. 개발 확인용으로 사용하고, 매일 정해진 시간의 모닝 루틴 운영에는 항상 실행되는 서버와 사전 음성 생성/캐시를 준비하세요. 이 안내는 실제 서비스를 생성하거나 유료 플랜을 구독하지 않습니다.

## 3. 모닝블록에 연결

1. 최신 미리보기 또는 모바일 앱에서 **내 루틴 → 클라우드 자연 음성**을 엽니다.
2. **여성 · Nova** 또는 **남성 · Onyx**를 선택합니다.
3. 서버 HTTPS 주소와 `TTS_ACCESS_TOKEN`을 입력합니다. 주소 끝에 `/tts`를 붙이지 않습니다.
4. **클라우드 연결·저장 → 현재 설정 음성 미리 듣기**를 누릅니다.
5. 뉴스 읽어주기와 외국어 리스닝 미리 듣기로 선택한 음성을 확인합니다. 생성된 AI 음성을 사용하며 팟캐스트는 원본 방송 음성을 유지합니다.

모바일 접속 토큰은 SecureStore, 웹은 해당 탭의 sessionStorage에 보관합니다. 웹 탭 세션이 끝나면 토큰을 다시 입력해야 할 수 있습니다. 기기 기본 음성으로 돌아가려면 **기기 음성 사용**을 누릅니다.

## 연결이 안 될 때

- Render의 배포/로그와 OpenAI 결제·API 키 권한을 확인합니다. 서버는 API 키나 접속 토큰을 로그에 출력하지 않습니다.
- HTTPS 서비스 주소, 토큰, 허용 origin이 정확한지 확인합니다.
- 무료 인스턴스가 잠들어 있다면 서버가 실행된 후 다시 미리 듣습니다.
- API 사용량은 OpenAI 대시보드에서 확인합니다. 서버는 텍스트를 OpenAI에 전달하고 음성을 메모리에 5분간 보관합니다.

현재 서버는 개인 개발용 인증 방식입니다. 여러 사용자에게 앱을 공개하기 전에는 사용자별 로그인·권한·사용량 제한, 모니터링과 콘텐츠 사전 생성 기능을 추가해야 합니다. 실제 휴대폰의 잠금 화면·오디오 인터럽트·모듈 시간 전환도 별도로 검증해야 합니다.

# 모닝블록

직장인을 위한 모듈형 오디오 모닝 루틴 앱. **예약 모닝콜 → 알림 한 번 터치 → 선택한 루틴을 화면 없이 듣기**가 중심 경험입니다.

## 프로젝트 기획·구현 메모

작성일: 2026-10-15 · 구현 기준: `3e9e31a` · 아래 기획 의도는 현재 코드와 작업 내용을 바탕으로 정리한 설계 메모입니다.

- [HTML 프로젝트 소개](docs/project-overview.html): 브라우저에서 열 수 있는 소개 문서. 외부 라이브러리 없이 열리며 인쇄도 가능합니다.
- [PowerPoint 발표 자료](docs/project-overview.pptx): 컨셉부터 후속 과제까지 정리한 9장 슬라이드. 본문은 편집 가능한 텍스트입니다.

### 컨셉 — 내 아침을 블록처럼 조립하다

- **한 문장 소개**: 직장인이 원하는 시간과 순서로 모듈을 조합하고, 음성으로 따라가는 모닝 루틴 앱.
- **목표 경험**: 예약 모닝콜 → 알림 터치 → 저장한 루틴 실행 → 화면을 오래 보지 않고 듣기 → 완료 기록.
- **서비스 톤**: 파스텔 색상과 블로키 캐릭터, 반원 다이얼로 부담 없이 작은 아침 습관을 시작한다.

### 기획 의도 — 바쁜 아침에 선택과 화면 조작을 줄이기

- **문제 가설**: 출근 준비 중 뉴스·학습·운동 앱을 오가면 흐름이 끊기고, 정해진 긴 루틴은 지속하기 어렵다.
- **설계 방향**: 스트레칭·뉴스·외국어·명상·팟캐스트의 시간과 순서를 사용자가 조절한다. 낭독 모듈도 편집 화면에서 추가할 수 있다.
- **기획 메모**: 기본 루틴과 오늘만 변경을 분리해 일상 변동에 대응한다. 이 의도는 설계 가설이며 사용자 조사나 효과 측정 결과는 아니다.

### 사용자 흐름 — 한 번 구성하고, 매일 가볍게 실행

- **01 구성**: 내 루틴에서 이름·시작 예정 시간·모듈을 설정한다. 모듈당 1~30분, 드래그로 순서를 바꾸고 여러 루틴을 저장한다.
- **02 실행**: 오늘 화면에서 수동 시작하거나 모바일 모닝콜 알림으로 연결 루틴을 실행한다. 오늘만 변경은 수동 실행에 적용된다.
- **03 회고**: 일시정지·재개 후 끝까지 마친 루틴을 기록한다. 중단·건너뛰기는 완료에서 제외하고 실제 진행 시간을 집계한다.

### 화면·상태 구현 — 구성과 실행을 분리한 앱 구조

- **화면**: 오늘·내 루틴·기록·모닝콜·설정 메뉴. ModuleDial의 반원 다이얼, 모드별 이미지, 접히는 설정 카드와 캐릭터 애니메이션.
- **상태·저장**: App.tsx에서 저장 루틴·오늘 변경·편집 초안·실행 세션을 구분한다. AsyncStorage에 루틴·기록·RSS 목록을 저장한다.
- **실행 제어**: 모듈 순서·남은 시간·일시정지 시간을 관리한다. 완료 기록은 일시정지 시간을 제외하며 한국 시간 달력으로 표시한다.

### 콘텐츠·오디오 구현 — 직접 작성한 레슨과 공개 RSS 연결

- **뉴스·외국어**: 뉴시스 RSS 제목·소개문을 읽는다. 기사 전문 수집·AI 요약은 구현하지 않았다. 4개 언어 × 3단계의 기본 레슨 12개를 제공한다.
- **팟캐스트**: 공개 HTTPS 오디오 RSS 등록·선택, 원본 오디오 재생, 이어 듣기 위치 저장. Luke 피드는 웹 읽기 제한 시 날짜가 표시된 스냅샷을 사용한다.
- **음성**: 기기 TTS와 언어별 음성 선택. 선택 기능인 클라우드 TTS는 별도 서버가 OpenAI tts-1-hd에 요청하며 Nova·Onyx를 지원한다.

### 최근 개선·검증 — 재현한 오류를 수정하고 회귀 검사 추가

- **개선 내용**: 모닝콜의 오늘 화면 복귀 오류, 잘못 저장된 기록의 화면 오류, 클라우드 사용 시 기기 음성 목록 누락을 수정했다. 실행되지 않는 안내 분기와 오래된 설명을 삭제했다.
- **자동 검증**: 2026-10-14 작업 기준: 타입 검사, 테스트 38개, web·iOS·Android 번들 내보내기 통과. 기준 커밋 3e9e31a.
- **브라우저 검증**: 루틴 생성·저장·삭제, 모닝콜 설정 저장, 오늘만 변경의 저장 분리, 일시정지·재개·완료 기록을 확인했다. 타이머 완료 검증은 가상 시간으로 수행했다.

### 한계·다음 단계 — 모바일 실사용 검증과 운영 준비

- **모바일**: 모닝콜은 OS 예약 알림이다. 웹은 설정만 저장한다. 실기기의 잠금 화면·무음/집중 모드·권한·오디오 인터럽트·장시간 백그라운드 전환은 추가 검증이 필요하다.
- **외부 연결**: 해당 작업에서 실시간 RSS 요청은 네트워크 정책으로 차단됐다. 클라우드 TTS는 연결 코드와 요청 거부 테스트를 검증했으며 실제 생성·청취는 미검증이다.
- **개발 우선순위**: 실기기 알림·재생 검증 → 백그라운드 재생 엔진과 콘텐츠 사전 준비 → 외부 피드·음성 연결 확인 → 사용자별 인증·사용량 제한·모니터링.

## 현재 기능

- 모듈별 1~30분 설정, 드래그 순서 변경, 여러 루틴 저장 및 오늘만 변경.
- 메인 반원 다이얼: 스트레칭·뉴스·외국어·명상·팟캐스트. 모드별 블로키 이미지와 UI 애니메이션, 접히는 설정 카드.
- 내 루틴에서 선택한 컬렉션을 시작 버튼으로 실행. 모닝콜 알림 터치는 알림에 연결된 저장 루틴을 바로 시작. 오늘만 수정한 내용은 수동 시작에 적용하며 예약 알림은 저장 루틴을 사용.
- 뉴스: 정치·경제·사회·생활/문화·IT/과학·세계. NEWSIS 공개 RSS 제목·소개문을 한국어로 읽음. 기사 전문 수집이나 AI 요약은 없음.
- 외국어: 영어·일본어·중국어·스페인어 × 초급·중급·고급. 직접 작성한 기본 레슨 12개, 듣기·질문·해설·따라 말하기.
- 팟캐스트: BBC Learning English Grammar / Conversations / 6 Minute English, Luke’s English Podcast. RSS에서 실제 오디오를 가져오며 최신 에피소드 또는 선택한 에피소드 재생, 이어 듣기 위치 저장.
- 설정 → 팟캐스트 추가·관리에서 공개 HTTPS 오디오 RSS 등록·삭제. 웹 CORS 제한이 있는 Luke 피드는 확인 날짜를 표시한 스냅샷 목록으로 대체하며, 모바일은 직접 요청.
- 설정 → 목소리 설정에서 언어별 설치 음성을 선택·미리 듣기. 팟캐스트 음성은 원본 방송 그대로 유지.
- 시·분 입력 및 증감 화살표, 요일별 모닝콜 예약. 모닝콜은 OS 예약 알림이며 지속적으로 울리는 기상 알람이 아님.
- 완료 횟수·누적 실제 진행 시간·연속 기록·한국 시간 기준 월별 달력. 건너뛰거나 중단한 루틴은 완료에 포함하지 않음. 이전 기록은 설정 시간을 사용한다고 표시.

루틴·기록·RSS 목록은 기기에 저장됩니다. 뉴스 소개문/레슨이 먼저 끝나면 남은 시간은 준비·복습 시간으로 사용합니다. 일시정지 후 뉴스·리스닝은 처음부터 다시 들으며, 팟캐스트는 현재 위치에서 이어집니다.

## 클라우드 남성·여성 음성

처음 연결한다면 [Render 서버 설치 안내](server/README.md)를 따라 진행하세요. 저장소 루트의 `render.yaml`로 개발용 서버를 만들 수 있습니다.

기기 기본 TTS 대신 OpenAI `tts-1-hd`의 Nova(여성 톤), Onyx(남성 톤)를 선택할 수 있도록 연결 코드를 제공합니다. AI 생성 음성임을 설정 화면에 표시합니다. **서버 및 API 키가 연결되지 않은 미리보기는 기기 TTS를 사용합니다.** 실제 자연스러움·발음은 연결 후 청취 검증이 필요합니다.

`server/tts.mjs`는 Node 22+에서 실행하는 개인 개발용 서버입니다. 호스팅 서비스의 비밀 환경 변수에 다음 값을 등록하세요. API 키를 앱 코드·GitHub·채팅에 넣지 마세요.

| 환경 변수             | 값                                    |
| --------------------- | ------------------------------------- |
| `OPENAI_API_KEY`      | OpenAI API 키                         |
| `TTS_ACCESS_TOKEN`    | 서버 접속용 무작위 토큰, 32자 이상    |
| `PUBLIC_BASE_URL`     | 서버의 HTTPS 주소                     |
| `TTS_ALLOWED_ORIGINS` | 허용할 웹 주소, 여러 개는 쉼표로 구분 |
| `PORT`                | 호스팅이 지정한 포트, 기본 8787       |

```sh
node server/tts.mjs
```

앱 설정 → 목소리 설정 → 클라우드 자연 음성에 서버 주소와 **서버 접속 토큰**을 입력하고 연결·저장을 누릅니다. OpenAI API 키는 서버에만 보관합니다. 모바일 접속 토큰은 SecureStore, 웹은 해당 탭의 sessionStorage에 보관합니다. 텍스트는 음성 생성을 위해 서버/OpenAI로 전송되며 API 사용료가 발생합니다.

서버는 인증·허용 Origin·텍스트 길이·요청 횟수를 검사하며 생성 오디오를 임의 URL로 5분간 메모리에 보관합니다. 이는 개인 개발 환경용입니다. 일반 사용자 배포 전에는 사용자별 인증·사용량 제한·운영 모니터링과 사전 음성 생성/캐시가 필요합니다. 현재 서버는 별도로 배포되지 않았습니다.

## 실제 기기에서 남은 확인

잠금 상태에서 알림 터치·앱 실행·오디오 자동 시작, 무음/집중 모드, 권한 거부, 전화/다른 오디오 인터럽트, 장시간 화면 잠금 상태의 정확한 모듈 전환을 검증해야 합니다. JS 타이머만으로 백그라운드에서 정확한 시간 전환을 보장하지 않습니다. 네이티브 알람과 백그라운드 재생 엔진, 콘텐츠 사전 준비가 다음 개발 우선순위입니다.

RSS는 공개 피드를 연결합니다. 상업적 서비스 공개 전 콘텐츠 제공자의 이용 조건을 확인해야 합니다.

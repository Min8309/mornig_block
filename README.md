# 모닝블록

내가 조립하는 아침. 직장인을 위한 모듈형 오디오 모닝 루틴 앱입니다.

## 실행

```sh
npm ci
npm start
```

동일한 Expo SDK를 지원하는 Expo Go 또는 개발 빌드에서 QR 코드를 열어 실행합니다. iOS 시뮬레이터는 macOS/Xcode, Android 에뮬레이터는 Android Studio가 필요합니다.

```sh
npm run typecheck
npx expo export --platform ios --platform android
```

## 첫 버전

- 크림/딥 틸 UI, 오늘·내 루틴·기록 탭
- 스트레칭·뉴스·영어·명상·낭독 모듈 추가/삭제
- 모듈별 1~30분 시간 설정 및 위/아래 순서 변경
- 모듈 취향 선택, 합산 시간 및 종료 예정 시각
- 여러 루틴 저장/선택 및 오늘만 수정
- AsyncStorage를 이용한 기기 내 설정과 완료 기록 저장
- 한국어 TTS 샘플 안내와 활동 타이머, 일시정지·다음 모듈·중단
- 끝까지 진행한 루틴만 완료 기록. 건너뛰기/중단은 완료 기록 제외

## 현재 범위와 다음 개발

이 버전은 실제 앱 소스이며 스토어 배포용 완성판이 아닙니다. 뉴스는 명시된 데모이고 최신 기사를 생성하거나 가져오지 않습니다. 취향 선택은 저장되지만 콘텐츠는 모듈별 고정 샘플입니다. 설정한 길이를 채우는 동적 오디오 콘텐츠는 후속 개발입니다. 샘플 안내 후에는 사용자가 활동할 시간이 이어집니다.

모닝콜 설정에서 시간·반복 요일·소리·연결할 루틴을 지정하면 iOS/Android 로컬 예약 알림을 등록합니다. 알림을 누르면 연결 루틴 화면을 준비하며 재생은 시작 버튼으로 실행합니다. 계속 울리는 네이티브 기상 알람이나 자동 오디오 시작은 구현하지 않았습니다. 웹에서는 설정 저장/미리보기만 지원하며 예약 알림을 등록하지 않습니다. 화면 잠금과 백그라운드에서 안정적인 오디오 재생, 잠금 화면 미디어 컨트롤, 이어폰/전화 인터럽트 처리는 네이티브 오디오 연동과 실기기 테스트가 필요합니다. 현재 JS 타이머는 앱 활성화 시 남은 시간을 재계산하며 앱 종료 후 세션 복원은 지원하지 않습니다. iOS 무음 모드에서 TTS 소리가 나지 않을 수 있습니다.

‘오늘만 수정’은 현재 세션 동안 유효하고 완료하면 해제됩니다. 일정/기록에는 개인정보를 외부 서버로 전송하는 코드를 사용하지 않습니다. 앱 삭제 시 로컬 데이터가 삭제됩니다.

다음 우선순위: 네이티브 알람 가능성 검증 → 백그라운드 오디오 엔진 → 길이/취향별 콘텐츠 → 실기기 사용성 검증.

## 모닝콜 확인

- 홈의 **아침 모닝콜 → 설정하기**에서 시간(HH:MM), 요일, 루틴, 소리를 지정합니다.
- 설정 저장 시 휴대폰 알림 권한을 요청하고 선택한 요일마다 주간 반복 알림을 예약합니다. 끄고 저장하면 이 기능이 만든 알림만 취소합니다.
- 테스트 버튼은 5초 뒤 알림을 예약합니다. 테스트는 휴대폰 개발 빌드에서 확인하세요.
- 현재 기기 현지 시간 기준입니다. 여행/시간대 변경 후 설정을 다시 저장하세요.
- 무음/집중 모드, 배터리 절전, Android 정확한 알람 권한에 따라 소리·시간이 달라질 수 있습니다. 정시 기상 보장은 하지 않습니다.
- expo-notifications 플러그인과 Android SCHEDULE_EXACT_ALARM 선언을 추가했습니다. 네이티브 설정 적용에는 개발 빌드를 새로 생성해야 합니다.
- 실기기 검증: 권한 허용/거부, 무음, 소리 끄기, 잠금 상태, 앱 종료, 재부팅, 요일 변경, 알림 중복 여부, 알림 탭 후 루틴 선택을 확인해야 합니다.
- `npm test`: 다음 요일/월 경계, 시간 검증, 예약 성공/실패/권한 거부/끄기 검증. 예약 API는 모의 실행 테스트이며 실제 전달 검증은 아닙니다.

## 블로키 모드 다이얼

홈의 오늘의 블록 카드를 눌러 블로키 모드를 전환하고, 펼쳐진 카드에서 시간과 취향을 직접 설정합니다. 모듈 추가/삭제 및 순서 변경은 루틴 편집 화면에서 제공합니다.

스트레칭은 운동복을 입은 두 포즈를 번갈아 재생하는 달리기 애니메이션, 뉴스는 안경·신문 포즈의 기울기, 영어는 공책·연필 포즈와 떠다니는 단어, 명상은 가부좌 포즈와 호흡 애니메이션입니다. 실시간 3D 모델이 아닌 생성된 2D 스프라이트와 UI 애니메이션이며 기기 움직임 줄이기 설정을 존중합니다. 재생 화면에도 동일한 활동별 블로키가 표시됩니다. 낭독은 별도 추가 버튼으로 유지합니다.

홈의 아침 요약 영역에는 원형 모드 다이얼을 표시하고, 오늘의 블록은 2열의 둥근 정사각형 그라데이션 버튼으로 표시합니다. 다이얼 또는 버튼으로 블로키 모드를 선택할 수 있습니다. 선택한 버튼 아래에 펼쳐진 설정에서 시간/취향을 변경하면 기기 내 기본 루틴(또는 오늘만 변경한 루틴)에 반영됩니다. 편집 화면의 모듈 추가는 카테고리 버튼으로 제공합니다. 영어 이미지에는 고유 렌더 키와 명시적인 고정 크기를 적용하고 이미지 로드 실패 시 기존 외국어 블로키를 대체 표시합니다.

루틴 편집의 위/아래 버튼은 드래그 핸들로 교체했습니다. 핸들을 잡아 이동하면 인접 카드가 자리를 비우고, 화면 가장자리에서는 자동 스크롤됩니다. 놓으면 순서가 변경되며 루틴 저장 시 유지됩니다. 보조기술은 핸들의 앞/뒤 이동 액션을 사용할 수 있습니다. 뉴스 카테고리는 정치·경제·사회·생활/문화·IT/과학·세계이며 기존 문화/IT·기술 설정은 로드 시 새 명칭으로 이전됩니다.
